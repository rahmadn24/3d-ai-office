## Brand & Style
The design system establishes an atmospheric, hyper-focused operating environment for next-generation intelligence orchestration and autonomous workspace management. It merges high-precision technical telemetry with cinematic depth, balancing the cold austerity of deep space with resonant bio-digital luminance. 

The aesthetic is grounded in **Technical Glassmorphism & Cyber-Minimalism**:
- Surface planes dissolve into deep void layers via calibrated backdrop blurs and micro-fine photon boundaries.
- Interactive states emit controlled luminescent glows rather than generic drop shadows, conveying high computational energy.
- Interface density is engineered for multi-stream AI orchestration, giving operators total situational awareness through quiet structural framing punctuated by targeted chromatic pulses.

## Colors
The palette is rooted in an abyss of ultra-deep blacks and slate-infused void tones, engineered to maximize the luminosity of primary telemetry accents without inducing visual fatigue.

### Color Architecture
- **Void Bases (Neutrals)**:
  - `canvas`: `#090A0F` — Absolute canvas substrate.
  - `surface-01`: `#0D0F18` — Base container tier for structural panels.
  - `surface-02`: `#141724` — Elevated interactive modules, hovering tiles, and inputs.
  - `surface-03`: `#1D2133` — Active states, selected nodes, and transient tooltips.
- **Accents & Luminescence**:
  - `primary` (`#00F0FF` - Electric Cyan): AI data streams, key interactive vectors, focus indicators, and mission-critical telemetry.
  - `secondary` (`#8A2BE2` - Violet Pulse): Synaptic orchestration pathways, complex multi-agent workflows, and ambient perimeter glow.
  - `tertiary` (`#10B981` - Neural Emerald): Operational harmony, affirmative status indicators, live nodes, and optimized energy footprints.
- **Micro-Boundaries & Text Tiers**:
  - `border-glass`: `rgba(255, 255, 255, 0.08)` — Standard hairline frame for all frosted panels.
  - `border-glow`: `rgba(0, 240, 255, 0.35)` — Charged active state highlight.
  - `text-primary`: `#F8FAFC` — High legibility data readouts and critical copy.
  - `text-secondary`: `#94A3B8` — Structural labels, operational metrics, and secondary context.
  - `text-muted`: `#475569` — Passive metadata, timestamps, and architectural guides.

## Typography
The typographic hierarchy balances futuristic mechanical rigor with contemporary ergonomic readability. 

- **Display & Headlines (`Space Grotesk`)**: Provides an engineered, tech-forward voice with deliberate geometric quirks. Used for macro views, dashboard titles, and key numeric aggregators. Tracking is pulled inward to build density.
- **Body & Structural Copy (`Plus Jakarta Sans`)**: Neutral, contemporary, and highly legible across dense data grids. Maintains soft geometry that offsets the sharp technical edges of the dark aesthetic.
- **Telemetry & Metadata (`JetBrains Mono`)**: Dedicated to node IDs, timestamps, token throughput, and sensor outputs. Always set with expanded tracking and strict tabular numeric alignment.

## Layout & Spacing
The layout follows a fluid-responsive multi-tier grid designed to handle both command-center overview monitors and mobile teleoperation devices.

### Grid & Breakpoints
- **Desktop / Command Display (1440px+)**: 12-column fluid grid with `2rem` gutters and `3rem` canvas margins. Enables dual pinned telemetry rails flanking a central workspace canvas.
- **Tablet / Operational Console (768px - 1439px)**: 8-column layout with `1.25rem` gutters and `2rem` margins. Side rails collapse into floating glass tool drawers.
- **Mobile Handheld (320px - 767px)**: 4-column stack with `1rem` gutters and `1rem` margins. Multi-metric modules reflow into horizontal swipe corridors.

### Spatial Rhythm
Internal card padding strictly utilizes `space-md` (`1rem`) for telemetry units and `space-lg` (`1.5rem`) for primary stage modules. Vertical stacking between distinct intelligence modules relies on `space-xl` (`2.5rem`) to maintain breathable separation despite dense content payloads.

## Elevation & Depth
Elevation is realized through atmospheric light layering and optical refraction rather than opaque shadow stacking.

### 1. Translucent Stratification
- **Tier 0 (Abyss)**: Solid `#090A0F` canvas with subtle background radial gradients of Violet Pulse (`rgba(138, 43, 226, 0.06)`) and Cyan (`rgba(0, 240, 255, 0.04)`).
- **Tier 1 (Surface Glass)**: `#0D0F18` at 70% opacity with `backdrop-filter: blur(16px)` and a continuous `1px solid rgba(255, 255, 255, 0.08)` border.
- **Tier 2 (Floating Pods)**: `#141724` at 80% opacity with `backdrop-filter: blur(24px)` and a top-edge highlight stroke of `rgba(255, 255, 255, 0.15)`.

### 2. Ambient Photonic Glows
Shadows are tinted and diffused:
- **Resting Elevation**: `0 8px 32px 0 rgba(0, 0, 0, 0.56)`.
- **Active / Focused Node**: `0 0 24px -4px rgba(0, 240, 255, 0.25), 0 8px 32px 0 rgba(0, 0, 0, 0.7)`.
- **System Alert / Override**: `0 0 30px -2px rgba(138, 43, 226, 0.3)`.

## Shapes
The structural language utilizes controlled, geometric precision. Radius level `2` (`0.5rem` / `8px`) provides the fundamental anchor for cards, input fields, and panels, striking an optimal middle ground between brutalist sci-fi industrialism and human-centered ergonomics.

- **Base Radius (`0.5rem`)**: Standard interactive items, cards, dialog boxes, and contextual menus.
- **Large Radius (`1rem`)**: Primary workspace containers and ambient backdrop pods.
- **Pill Geometry (`9999px`)**: Reserved exclusively for telemetry status badges, filter chips, and circular icon triggers to visually contrast structural glass panes.

## Components

### Buttons
- **Primary (Electric Cyan)**: Solid `#00F0FF` background, text in `#090A0F` (`font-weight: 600`), minimal border. Hover triggers an outer cyan aura: `box-shadow: 0 0 20px rgba(0, 240, 255, 0.4)`.
- **Secondary (Glass Neural)**: Background `rgba(255, 255, 255, 0.03)`, `1px solid rgba(255, 255, 255, 0.08)`, text `#F8FAFC`. Hover shifts background to `rgba(255, 255, 255, 0.07)` and border to `rgba(0, 240, 255, 0.4)`.
- **Destructive**: Void dark surface with `rgba(239, 68, 68, 0.2)` border, text `#EF4444`, shifting to full red ambient back-glow on hover.

### Telemetry Badges & Chips
- Fully radiused pills utilizing `label-xs` in `JetBrains Mono`.
- Backgrounds set to 10% accent opacity with a matching 20% accent border (e.g., neural emerald badge: `bg: rgba(16, 185, 129, 0.1)`, `border: rgba(16, 185, 129, 0.25)`, `color: #10B981`).
- Feature an animated micro-ping dot indicating live sensor connection or agent readiness.

### Input Fields
- Surface `#0D0F18` overlaid with `backdrop-filter: blur(12px)`.
- Border `1px solid rgba(255, 255, 255, 0.08)`. Placeholder text set to `text-muted` (`#475569`).
- Focus state instantly activates a `1px solid #00F0FF` boundary accompanied by a soft glow: `box-shadow: 0 0 12px rgba(0, 240, 255, 0.2)`.

### Cards & Glass Panels
- Constructed from Tier 1 or Tier 2 glass layers.
- Hairline top edge: `border-top: 1px solid rgba(255, 255, 255, 0.12)` mimics downward physical illumination.
- Hoverable workspace cards display an inward radial gradient following the cursor position using micro-opacity cyan.

### Checkboxes & Radios
- Sharp geometric squares (checkbox, `rounded: 4px`) and circles (radios).
- Resting state: `1.5px solid rgba(255, 255, 255, 0.2)` against deep void background.
- Selected: `#00F0FF` fill with dark checkmark/indicator and active cyan halo.

### Specialized AI & Office Modules
- **Neural Agent Status Node**: Card component with an integrated radial pulse ring indicating active inference cycles, token consumption counter, and instant kill/reroute switches.
- **Spatial Telemetry HUD**: Floating frosted mini-module displaying smart office climate, acoustic dampening levels, and active robotic occupancy with monospace data readouts.
