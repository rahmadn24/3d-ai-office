# Naskah 02 — "Bikin Web Berapa Sih? Jawab Sekali Jadi" (Reels, pilar: harga)

Hook (3 detik pertama, teks + ucap):
"Bikin web berapa sih? Jawabannya: tergantung 3 hal ini — tonton 30 detik."

Isi (scene):
1. (0-5 dtk) To-camera: "Paling sering ditanya di DM: berapa bikin web? Jawab sekali jadi di sini."
2. (5-15 dtk) B-roll + teks: "Hemat buat landing simpel, Bisnis buat company profile + katalog, Custom buat butuh khusus."
3. (15-25 dtk) To-camera: "Yang bikin harga naik-turun: jumlah halaman, fitur (katalog/checkout/integrasi), sama materi siap atau belum."
4. (25-30 dtk) "Estimasi pasti keluar setelah 5 menit brief — gratis, nggak maksa."

CTA:
"Mau angka pastinya? DM HARGA, tulis usahamu apa + butuh halaman apa."
